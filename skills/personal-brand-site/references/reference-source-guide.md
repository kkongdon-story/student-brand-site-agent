# Reference Source Guide

Use this guide in Stage 2 when a student asks "where should I find references?" Do not give every site at once. Pick 2-4 sources based on the student's situation.

## Rule

The student should not wander through dozens of galleries. Give them a small mission:

```text
Find 1 reference for structure, 1 reference for mood, and 1 reference for motion/component.
For each reference, bring the URL plus one screenshot or one sentence about the exact part you like.
```

## Situation-Based Source Map

| Student situation | Recommended sources | What to look for | What to give the AI |
| --- | --- | --- | --- |
| "I want a beautiful personal brand homepage." | Lapa Ninja, Siteinspire, Awwwards | First viewport, personal storytelling, typography, nav, final CTA | URL, first-screen screenshot, liked section, bring/avoid memo |
| "I want a landing page that makes people apply or contact me." | Lapa Ninja, One Page Love, Landing Love | Hero copy, CTA position, proof, FAQ, final CTA | URL, hero screenshot, CTA wording, section order |
| "I want Hongdae/editorial/creative mood." | Awwwards, Siteinspire, curated.design | Typography, spacing, image treatment, texture, unusual layout | Screenshot, mood words, color/material notes, what not to copy |
| "I want AI/Web3/startup style but not boring." | Godly, Awwwards, Landing Love | Strong hero, productized personal brand, motion, dark/light style | URL, hero screenshot, component/motion notes |
| "I only need button/nav/CTA ideas." | Navbar Gallery, CTA Gallery, Collect UI | Navigation, CTA block, footer CTA, button states | Screenshot, component name, desired behavior |
| "I want app-like movement or micro-interactions." | 60fps, Mobbin | Hover, tap, scroll, reveal, transition, mobile states | Motion description, frame screenshots, interaction prompt |
| "I need color and font help." | Coolors, Fontpair, Google Fonts | Palette, font pairing, contrast, readability | Hex colors, font names, usage rule |
| "I need logos, icons, or brand assets." | SVGL, Hugeicons, Rebrand Gallery, Logofolio | Icon style, logo treatment, brand system, line weight | Asset link, icon style, line weight, usage rule |
| "I want ready-made component ideas." | 21st.dev, Component Gallery | Cards, navs, forms, pricing, testimonials, UI patterns | Component URL, component name, what to adapt |

## Source Notes

### Lapa Ninja

Best for finished landing pages and personal/startup pages. Use it when the student needs a real page, not just a design shot.

Student task:

- Choose one page with a strong first screen.
- Screenshot the hero and one lower section.
- Write what to bring and what to avoid.

### Awwwards

Best for high-end visual direction, unusual layout, and premium motion. It can be overwhelming for beginners, so give one clear task.

Student task:

- Do not browse randomly for more than 10 minutes.
- Pick one visual feeling: typography, texture, layout, or scroll.
- Bring only the exact page or screenshot.

### Siteinspire / curated.design

Best for editorial, portfolio, cultural, studio, and less template-like sites.

Student task:

- Look for mood and layout, not conversion copy.
- Bring a screenshot plus "why this feels good."

### Godly

Best for AI, Web3, startup, and productized personal brands. Use it when the student wants modern tech energy.

Student task:

- Pick one hero layout or one motion/component idea.
- Avoid copying the whole color system if it clashes with the student's brand.

### Landing Love / One Page Love

Best for one-page flow, offer structure, CTA repetition, and page order.

Student task:

- Capture hero, proof, FAQ or final CTA.
- Use it to decide page structure, not only style.

### Navbar Gallery / CTA Gallery / Collect UI

Best when the student likes the overall site but needs a specific component.

Student task:

- Choose one component only.
- Name the component: nav, CTA block, button, footer, card, proof rail.

### Mobbin / 60fps

Best for motion and interaction ideas. Use when the student says "I want it to feel alive."

Student task:

- Describe the movement in plain words.
- Capture before/after states if possible.
- Convert it into hover, click, or scroll prompt language.

### Coolors / Fontpair

Best for simple visual system decisions.

Student task:

- Choose 3-5 colors only.
- Choose one heading font direction and one body font direction.
- Keep readability more important than style.

### SVGL / Hugeicons / Rebrand Gallery / Logofolio

Best for brand identity, logo treatment, and icon style.

Student task:

- Use these as style references, not as proof that the brand owns those assets.
- Record line weight, fill style, and whether icons should feel friendly, technical, editorial, or playful.

### 21st.dev / Component Gallery

Best for component vocabulary and ready-made UI patterns.

Student task:

- Use component names to talk to AI: Navigation Bar, Hero, CTA, Testimonial, FAQ, Footer, Card Grid.
- Do not add a full component library unless the build stack already uses one.

## What The Student Must Bring Back

For each of the three selected references:

```text
1. Source URL or screenshot path:
2. Which part I like:
3. What my website should borrow:
4. What my website must not copy:
5. AI-readable material:
   - URL only / screenshot / color palette / font pair / component name / motion description / code idea
```

## Agent Output

After the student brings references, produce:

- `reference-dna.md`
- `prompt-pack.md`
- capture tasks for any missing screenshot
- `DESIGN.md` language for reference, visual direction, design system constraints, and motion
