# 레퍼런스 사이트 고르는 법

홈페이지를 만들 때 참고 사이트를 너무 많이 보면 오히려 멈춥니다.

수업에서는 딱 3개만 고릅니다.

1. 구조 참고: 첫 화면과 섹션 순서가 좋은 사이트
2. 분위기 참고: 색감, 폰트, 질감이 좋은 사이트
3. 움직임 참고: 마우스나 스크롤 반응이 좋은 사이트

## 상황별 추천

| 내가 원하는 것 | 먼저 볼 사이트 | 무엇을 보면 되나요? |
| --- | --- | --- |
| 개인 브랜드 홈페이지 | Lapa Ninja, Siteinspire, Awwwards | 첫 화면, 큰 문장, 소개 흐름, 마지막 CTA |
| 신청/상담으로 이어지는 랜딩페이지 | Lapa Ninja, One Page Love, Landing Love | 버튼 위치, 섹션 순서, FAQ, 마지막 신청 영역 |
| 홍대 감성, 감각적인 편집 디자인 | Awwwards, Siteinspire, curated.design | 타이포그래피, 여백, 이미지 배치, 질감 |

| 버튼, 메뉴, CTA만 참고 | Navbar Gallery, CTA Gallery, Collect UI | 네비게이션, CTA 박스, 버튼 상태 |

| 컴포넌트 이름 배우기 | 21st.dev, Component Gallery | Hero, Navigation Bar, CTA, Card, FAQ 같은 부품 이름 |

## 사이트별 사용법

### Lapa Ninja

완성된 랜딩페이지를 보기 좋습니다.

이럴 때 쓰세요:

- 개인 브랜드 페이지를 만들고 싶을 때
- 첫 화면 구성을 참고하고 싶을 때
- 신청 버튼이 어디에 들어가야 하는지 보고 싶을 때

가져올 것:

- URL
- 첫 화면 스크린샷
- 마음에 드는 섹션 하나

### Awwwards

감각적인 웹사이트를 보기 좋습니다. 다만 초보자에게는 너무 많고 어려울 수 있습니다.

이럴 때 쓰세요:

- 흔한 AI 템플릿처럼 보이고 싶지 않을 때
- 타이포그래피나 움직임이 강한 사이트를 보고 싶을 때
- 고급스러운 분위기를 참고하고 싶을 때

가져올 것:

- 마음에 드는 화면 하나
- 어떤 점이 좋은지 한 문장
- 절대 따라 하면 안 되는 점

### Siteinspire / curated.design

포트폴리오, 스튜디오, 에디토리얼 느낌을 보기 좋습니다.

이럴 때 쓰세요:

- 홍대 감성, 잡지 같은 느낌, 독립 브랜드 느낌을 찾고 싶을 때
- 색감보다 레이아웃과 분위기를 보고 싶을 때

가져올 것:

- URL
- 첫 화면 또는 섹션 스크린샷
- “이 사이트의 어떤 느낌을 가져오고 싶은지”

### Godly

AI, Web3, 스타트업 느낌의 사이트를 보기 좋습니다.

이럴 때 쓰세요:

- 기술 브랜드 느낌을 내고 싶을 때
- 현대적인 첫 화면을 참고하고 싶을 때

주의할 점:

- 너무 어둡거나 비슷한 AI 느낌으로 흐를 수 있습니다.
- 내 브랜드와 맞지 않으면 색감은 가져오지 않아도 됩니다.

### Landing Love / One Page Love

한 페이지 안에서 설득 흐름을 보기 좋습니다.

이럴 때 쓰세요:

- 상담 신청, 자료 신청, 상품 판매 페이지를 만들 때
- 섹션 순서를 보고 싶을 때

가져올 것:

- hero
- proof
- FAQ 또는 final CTA

### Navbar Gallery / CTA Gallery / Collect UI

전체 사이트보다 작은 부품을 보기 좋습니다.

이럴 때 쓰세요:

- 상단 메뉴가 마음에 안 들 때
- 버튼이나 신청 영역만 고치고 싶을 때
- AI에게 부품 이름으로 정확히 말하고 싶을 때

가져올 것:

- 부품 스크린샷
- 부품 이름: Navigation Bar, CTA, Button, Footer, Card

### Mobbin / 60fps

움직임과 앱 같은 반응을 보기 좋습니다.

이럴 때 쓰세요:

- 마우스를 올렸을 때 반응이 있었으면 좋겠을 때
- 클릭하면 문구나 상태가 바뀌었으면 좋겠을 때
- 스크롤할 때 섹션이 자연스럽게 나왔으면 좋겠을 때

가져올 것:

- 움직임 전후 화면
- “어떻게 움직이는지” 한 문장

### Coolors / Fontpair

색과 폰트를 빨리 정하기 좋습니다.

이럴 때 쓰세요:

- 색 조합이 감이 안 올 때
- 제목 폰트와 본문 폰트 조합이 필요할 때

가져올 것:

- 색상 코드 3-5개
- 제목용 폰트 느낌
- 본문용 폰트 느낌

## 수업에서 가져오면 되는 형식

레퍼런스 하나마다 아래처럼 적으면 됩니다.

```text
1. 사이트 주소 또는 스크린샷:
2. 마음에 드는 부분:
3. 내 홈페이지가 가져오면 좋을 것:
4. 절대 그대로 따라 하면 안 되는 것:
5. AI에게 줄 자료:
   URL / 스크린샷 / 색상 / 폰트 / 부품 이름 / 움직임 설명
```

## 중요한 기준

레퍼런스는 베끼는 대상이 아닙니다.

레퍼런스는 내가 원하는 감각을 AI가 이해할 수 있게 바꿔주는 재료입니다.
